# rdl-ts

A TypeScript library project for parsing, analyzing, creating, and editing SystemRDL source. It targets browser and Node.js consumers, with source-preserving edits, standard UDP validation, and errors as values through Effect.

Design planning is complete. The library is not implemented yet.
